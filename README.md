# Melody Dash Landing Site

A modern, neon-styled marketing site for the Melody Dash mobile rhythm runner, built with Next.js App Router, TypeScript, Tailwind CSS, and Framer Motion.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Project Structure

- `app/` — App Router pages and components
- `app/components/` — Reusable UI components (Button, Card, Modal, etc.)
- `app/data/siteData.ts` — Single source of truth for site content and links
- `public/` — Placeholder assets (screenshots, OpenGraph image, favicon)

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the dev server:
   ```bash
   npm run dev
   ```
3. Visit `http://localhost:3000`.

## Editing Content

Update `app/data/siteData.ts` to modify hero copy, CTA links, features, testimonials, FAQ items, and placeholder assets.
